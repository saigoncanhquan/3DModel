# 3D CAD Model: PP-4

Trang xem 3D tương tác bóc tách linh kiện (Untube 3D Engine).

## Hướng dẫn kích hoạt & Quản lý Gallery Showcase:
1. Chạy file `deploy.bat` trong thư mục này để đồng bộ và đẩy mô hình lên nhánh `gh-pages` trên GitHub.
2. Script tự động đưa mô hình vào thư mục `/PP-4/` và cập nhật trang chủ Gallery (`index.html`) tại root của nhánh `gh-pages`.
3. Các mô hình cũ đã tải lên trước đó được bảo toàn 100%, không bị ghi đè hay mất dữ liệu.
4. Vào Settings > Pages của Repository trên GitHub, chọn branch `gh-pages` (root) để nhận liên kết xem online miễn phí vĩnh viễn!
