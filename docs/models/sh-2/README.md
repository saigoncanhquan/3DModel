# 3D CAD Model: sh22

Trang xem 3D tương tác bóc tách linh kiện.

## Hướng dẫn kích hoạt GitHub Pages:
1. Commit và push thư mục này vào nhánh `main` hoặc `gh-pages` trên GitHub.
2. Vào Settings > Pages của Repository.
3. Tại 'Build and deployment', chọn 'Deploy from a branch' và chọn thư mục chứa file `index.html`.
4. Nhận link xem online miễn phí vĩnh viễn!
