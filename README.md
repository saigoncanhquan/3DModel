# 3D CAD Model: Unnamed-par33

Trang xem 3D tương tác bóc tách linh kiện.

## Hướng dẫn kích hoạt GitHub Pages:
1. Chạy file `deploy.bat` bên dưới để tự động tạo và đẩy lên nhánh `gh-pages` trên GitHub.
2. Hoặc commit thủ công và push thư mục này vào nhánh `main` hoặc `gh-pages` trên GitHub.
3. Vào Settings > Pages của Repository.
4. Tại 'Build and deployment', chọn 'Deploy from a branch' và chọn thư mục chứa file `index.html`.
5. Nhận link xem online miễn phí vĩnh viễn!
